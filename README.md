# React-MERN-Stack-E-Commerce

Full stack MERN e-commerce application developed with React, Node.js, Express.js, and MongoDB featuring authentication, product management, shopping cart functionality, and responsive UI design.

---

## Overview

React-MERN-Stack-E-Commerce is a full stack e-commerce application built using the MERN stack. The project focuses on modern web development concepts such as authentication systems, dynamic product management, RESTful APIs, responsive UI development, and full stack application architecture.

The application provides a complete shopping experience including product browsing, cart management, and user-focused interface interactions.

---

## Key Features

* Full stack MERN architecture
* Product listing and management
* Shopping cart functionality
* User authentication and authorization
* RESTful API integration
* Dynamic UI components

* MongoDB database integration
* Frontend and backend communication

## Architecture

The project follows a MERN stack architecture structure for scalable full stack web application development.

### Application Structure

* Frontend (React.js)
* Backend API (Node.js & Express.js)
* Database Layer (MongoDB)

This structure provides clean separation between frontend and backend systems while supporting scalable application development.

## Installation

### Clone the repository

```bash
git clone https://github.com/anilates97/React-MERN-Stack-E-Commerce.git
```

### Navigate to the project directory

```bash
cd React-MERN-Stack-E-Commerce
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file and configure the required MongoDB connection settings.

### Run the development server

```bash
npm start
```
